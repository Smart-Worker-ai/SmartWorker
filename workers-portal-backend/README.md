# Workers Portal Backend

Express API scaffold for the Workers Portal MVP.

## Included

- `GET /api/v1/health` health check
- Encryption helper for vault data
- Middleware placeholder for API-level error handling
- Environment sample for Neon, Supabase, and Firebase integration

## Run

1. Copy `.env.example` to `.env`.
2. Install dependencies with `npm install`.
3. Start the server with `npm run dev`.
