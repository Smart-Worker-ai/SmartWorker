# Workers Portal App

Flutter feature-first scaffold for the Workers Portal MVP.

## Included

- Custom theme baseline
- Dio API client with JWT interceptor pattern
- Secure storage wrapper for auth tokens
- Welcome screen placeholder for the Crewzo login experience

## Next Steps

1. Run `flutter create .` inside this folder if you want Flutter to generate the missing platform folders.
2. Add your Figma-driven UI into `lib/features/auth/` and related feature folders.
3. Connect the API client to the backend base URL and token provider.
